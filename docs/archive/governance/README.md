# Histórico de gobierno y decisiones

**Estado:** Histórico
**Índice vigente:** [`../../README.md`](../../README.md)

Este directorio conserva evidencia cerrada de gobierno, versionado, auditoría y
decisiones. NOR.2 R5 incorpora aquí **25 documentos** clasificados como
`ARCHIVAR` por la matriz R2, además de snapshots históricos ya existentes.

Los archivos conservan su contenido histórico y no sustituyen los documentos
vigentes de `docs/governance/`, `docs/decisions/` ni el estado público del
repositorio.
