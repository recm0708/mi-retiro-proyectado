# Archivo histórico de documentación

**Clasificación:** Histórico
**Índice vigente:** [`../README.md`](../README.md)
**Normalización vigente:** NOR.2 R5 — archivo y consolidación histórica

Este directorio conserva documentación que describe estados, auditorías,
revisiones o estructuras anteriores de Mi Retiro Proyectado.

Un archivo histórico **no define el comportamiento vigente**. Git continúa
siendo la evidencia primaria de autoría, fecha, hash y contenido exacto; el
archivo documental agrega contexto de lectura cuando ese valor histórico es
útil.

## Organización

- [`governance/`](governance/) — cierres, auditorías, decisiones y evidencia de
  gobierno/versionado.
- [`technical/`](technical/) — auditorías técnicas cerradas y snapshots previos.
- [`ux/`](ux/) — auditorías y bitácoras UX históricas.

NOR.2 R5 traslada a estas áreas los documentos cerrados que la matriz R2
clasificó como `ARCHIVAR`. No se crean stubs permanentes en las rutas antiguas.

## Regla de navegación

Para conocer el estado actual se consulta primero [`../README.md`](../README.md)
y las áreas documentales vivas (`architecture/`, `decisions/`, `governance/`,
`operations/`, `product/`, `regulatory/`, `security/` y `standards/`).

Los documentos históricos pueden conservar enlaces, rutas y nombres que eran
válidos en su contexto original. No se reescriben masivamente para aparentar
vigencia posterior.
