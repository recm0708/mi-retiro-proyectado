# Estándares de documentación

## Propósito

Define cómo se crean, mantienen y reemplazan documentos del proyecto.

## Documentos actuales

Debe existir una única versión oficial para cada política o norma.

No deben mantenerse múltiples archivos como:

```text
documento-final.md
documento-final-v2.md
documento-nuevo.md
```

## Sustitución de documentos

Cuando un documento sea reemplazado:

1. se conserva el contenido válido;
2. se crea el nuevo documento oficial;
3. se actualizan referencias;
4. se validan enlaces y pruebas;
5. se elimina el documento anterior del árbol actual.

El historial permanece disponible en Git.

## Idioma

La documentación se redacta en español.

Los términos técnicos se mantienen cuando son nombres oficiales o conceptos
estandarizados.
