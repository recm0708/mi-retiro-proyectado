# Convenciones de nombres

## Propósito

Establece las reglas para nombrar carpetas, archivos y componentes nuevos.

## Carpetas

Las carpetas técnicas utilizan nombres en inglés y formato consistente.

Ejemplos:

```text
services/
models/
templates/
validation_cases/
```

No se utilizan espacios ni caracteres especiales.

## Archivos de código

Los archivos Python utilizan formato snake_case.

Ejemplos:

```text
salary_projection.py
observability.py
centro_desarrollo.py
```

## Archivos técnicos

Los nombres técnicos mantienen las convenciones utilizadas por sus ecosistemas.

Ejemplos:

```text
requirements.txt
docker-compose.yml
```

## Documentación Markdown

Los documentos técnicos internos pueden utilizar nombres en inglés para mantener
uniformidad técnica.

Ejemplo:

```text
repository-structure.md
naming-conventions.md
```

El contenido interno de estos documentos permanece en español.

## Excepciones

Los nombres oficiales de tecnologías, estándares o sistemas se conservan.

Ejemplos:

```text
FastAPI
GitHub
Python
CSS
HTML
JSON
```

## Renombrados

Un renombrado debe revisar referencias, imports, pruebas, enlaces y documentos
antes de eliminar la ruta anterior.
