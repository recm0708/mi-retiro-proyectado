# Archivo histórico de documentación

**Clasificación:** Histórico
**Creado en:** GOV.1.3 R1 — 2026-08-17

Este directorio conserva documentación que describe estados, revisiones o estructuras anteriores de Mi Retiro Proyectado.

## Regla principal

Un archivo histórico **no define automáticamente el comportamiento vigente**.

Debe utilizarse para responder preguntas como:

- ¿qué se diseñó inicialmente?;
- ¿qué problema originó una revisión?;
- ¿qué pruebas se planificaron o ejecutaron?;
- ¿qué regla fue sustituida después?;
- ¿cómo evolucionó una fase?;
- ¿qué información contenían los documentos antes de una reorganización?

Para conocer el estado actual se debe consultar primero `docs/INDICE.md` y los documentos vigentes.

## Contenido

### `ux/`

Bitácoras completas de UX.4.6a–d. Se conservan con su contenido histórico, incluso cuando dentro de ellas aparecen estados intermedios posteriormente superados.

Las antiguas rutas `docs/UX_4_6*.md` se mantienen como archivos de compatibilidad que remiten a estas copias históricas.

### Snapshots pre-GOV.1.3

- `CHANGELOG_PRE_GOV1_3.md` — changelog acumulativo anterior a la reorganización.
- `ROADMAP_PRE_GOV1_3.md` — roadmap anterior a la reorganización.

Estos snapshots permiten auditar qué decía la documentación inmediatamente antes de GOV.1.3 sin depender únicamente de una comparación Git.

## Evidencia primaria

Git sigue siendo la evidencia primaria del historial:

- hash;
- autor;
- fecha;
- mensaje;
- contenido exacto de cada commit.

Los documentos históricos son una capa de lectura y contexto; no reemplazan esa evidencia.
